# YouTube Clone Project

This repository contains multiple versions of a YouTube-inspired clone project:

- Original HTML/CSS/JavaScript version in the folder "Youtube_1st verision"
- Another version in the folder "Youtube-Clone"
- A modern React + Vite version in the folder "youtube-clone-react"

## Project Structure

- "Youtube_1st verision" - static website version
- "Youtube-Clone" - another static implementation
- "youtube-clone-react" - React-based version

## How to Run

For the React version, open the folder "youtube-clone-react" and run:

```bash
npm install
npm run dev
```

## Notes

This repository keeps all project folders together without removing any existing content.
